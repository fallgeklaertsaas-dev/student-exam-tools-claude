# Program snapshot / Programmübersicht

Source / Quelle: [Claude for Open Source](https://claude.com/contact-sales/claude-for-oss), 2026-11-11. Alternative routes / Alternative Zugangswege:

| Route / Zugang | Published threshold / Veröffentlichte Schwelle |
| --- | --- |
| Package maintainer / Paket-Maintainer | ≥500 dependent repos / abhängige Repos **or/oder** ≥100 dependent packages / abhängige Pakete **or/oder** ≥200,000 monthly downloads / monatliche Downloads |
| Core contributor / Kernbeitrag | Listed committer or maintainer, recognized foundation/language project / Gelisteter Committer oder Maintainer eines anerkannten Stiftungs-/Sprachprojekts |
| Active contributor / Aktive Beiträge | ≥100 authored merged PRs in unowned repos, 12 months / eigene zusammengeführte PRs in fremden Repos, 12 Monate |
| Community builder / Community-Aufbau | ≥20 unique external contributors with merged PRs in one repo, 12 months / unterschiedliche externe Mitwirkende mit zusammengeführten PRs in einem Repo, 12 Monate |
| Critical infrastructure / Kritische Infrastruktur | Maintained repo with OpenSSF criticality score ≥0.4 / betreutes Repo mit OpenSSF-Criticality-Score ≥0,4 |
| Exception / Ausnahme | Explain work the ecosystem depends on / Bedeutung für das Ökosystem erläutern |

No eligibility claim is made for this new project. Für dieses neue Projekt wird keine erfüllte Teilnahmeberechtigung behauptet.
