# Community-Entwicklungsplan — Deutsch

[English](community-en.md)

## Zweck des Projekts

Studentische Lernwerkzeuge sollen Denkwege nachvollziehbar machen: ein verständlicher Hinweis, ein Diagramm mit ausdrücklichen Annahmen und ein prüfbares Ergebnis. Die erste Version konzentriert sich auf diese Grundlagen statt auf eine große Sammlung ungeprüfter Lektionen.

## Nächste Meilensteine

| Stufe | Nötige Nachweise vor Abschluss |
| --- | --- |
| Funktionsfähige Alpha | Reproduzierbare Codetests, gültige Skill-ZIPs, deutsche/englische Anweisungen und klare Grenzen |
| Claude-Kompatibilität | Beide Sprachen in einem echten Claude-Konto und lokalem Claude Code installieren; Version, Prompts, Ausgaben und Fehler erfassen |
| Rückmeldungen von Lernenden | Freiwillige anonymisierte Versuche; unverständliche Erklärungen erkennen; Zitate nur mit Erlaubnis verwenden |
| Weitere Darstellungen | Zahlengeraden sowie Vektor-/Matrixgrafiken mit mathematischen Tests und zugänglichen Beschreibungen ergänzen |
| Gepflegtes Community-Projekt | Nützliche externe Änderungen prüfen, auf nachvollziehbare Fehler reagieren und dokumentierte Versionen veröffentlichen |

Geeignete erste Beiträge: ein zweisprachiger Evaluationsfall, eine verständlichere XML-Namensraumerklärung, eine zugängliche Bildbeschreibung, ein echter Fehlernachweis oder eine an der Ausgangsgleichung geprüfte Lektion. Das sind Vorschläge, keine künstlichen Issues oder bereits geleisteten Beiträge.

## Ehrliche Einordnung zum Open-Source-Programm

Ein professionelles neues Repository allein belegt keine Teilnahmeberechtigung. Siehe die zweisprachige [Kriterienübersicht](program-criteria.md) und das aktuelle [offizielle Programm](https://claude.com/contact-sales/claude-for-oss).

Dokumentiere tatsächliche externe Mitwirkende, URLs zusammengeführter PRs, Weiterverwendung und echte Rückmeldungen. Kaufe oder erfinde keine Interaktionen. Über die Aufnahme entscheidet Anthropic; das Projekt kann keine Annahmewahrscheinlichkeit garantieren.
