# Community roadmap — English

[Deutsch](community-de.md)

## Why this exists

Student-led tools should make the reasoning inspectable: a readable hint, a diagram whose assumptions are explicit, and a result that can be checked. The first release focuses on these building blocks rather than a large catalog of untested lessons.

## Next milestones

| Stage | Evidence needed before calling it complete |
| --- | --- |
| Working alpha | Reproducible code tests, valid skill ZIPs, EN/DE instructions and clear limits |
| Claude compatibility | Install each locale in a real Claude account and local Claude Code; record version, prompts, outputs and failures |
| Learner feedback | Voluntary anonymized trials with actual learners; identify confusing explanations; obtain permission before quoting feedback |
| Better visual coverage | Add number-line and vector/matrix visuals only with mathematical tests and accessible descriptions |
| Maintained community project | Review useful external changes, respond to reproducible bugs and publish documented releases |

Good first contributions: a bilingual evaluation case, a clearer explanation of XML namespaces, an accessible diagram description, a genuine bug reproduction, or a lesson verified against its original equation. These are suggestions, not fabricated issues or completed contributions.

## Honest Open Source program readiness

A polished new repository alone establishes no eligibility. See the bilingual [program criteria snapshot](program-criteria.md) and the current [official program](https://claude.com/contact-sales/claude-for-oss).

Record actual external contributors, merged PR URLs, downstream use and genuine feedback over time. Never buy or fabricate engagement. Application decisions belong to Anthropic; this project cannot guarantee an acceptance probability.
